# CLAUDE.md — Rozbirka Design System

Пакет описує, як має виглядати й поводитися кабінет Rozbirka (CRM/ERP для розбірок). Джерело правди — код `rozbirka/rozbirka.web@main`. Цей пакет — цільова система v2 разом із мапою переходу з поточного коду. Репо не змінювати.

## Порядок читання
1. `v2/tokens.css`: кольори, шрифти, відступи, радіуси, теми, щільність.
2. `v2/kit.css` + `v2/CATALOG.md`: класи `.rz-*` і відповідність компонентам репо.
3. `v2/components/*.dc.html`: еталони кожного компонента в усіх станах.
4. `v2/modules/Index.dc.html` → сторінка потрібного модуля (`v2/modules/NN Назва.dc.html`): усі екрани модуля по порядку — список, картка, форма, шторки, діалоги, тости, кожен стан окремим кадром. `v2/archive/` — старі збірні сторінки, не використовувати.
   - Сторінки 00–44 (крім 10 і 11) — однаковий шаблон; зміст модуля лежить у `v2/modules/data/NN.js` (номер = перші дві цифри імені файлу), будівельні функції — `v2/modules/kit.js`, тексти шторок — `data/drawers.json`, екранів — `data/screens/*.json`. Щоб змінити модуль, редагуй лише його `data/NN.js`.
   - Один кадр: `?f=2.4`; один розділ: `?s=2`.
5. `OPEN-QUESTIONS.md`: відкриті питання й прийняті рішення. Позначене `?` не вирішувати самостійно.
6. За потреби: `v2/MIGRATION.md` (as-is → v2), `tokens/DRIFT.md` (розбіжності в коді).

## Жорсткі правила
- Підключати `tokens.css` → `kit.css` → lucide-static font. На `<body>`: `class="rz" data-theme="dark|light" data-density="compact|comfortable"`.
- Використовувати лише класи з `kit.css` і змінні `--rz-*`. Не додавати hex-кольорів, нових радіусів, тіней чи розмірів шрифту.
- Іконки — lucide-static, розмір лише з `--rz-icon-xs/sm/(base)/md/lg` (10/12/14/16/20). Фіксовані кольори поза темою — `--rz-on-solid`, `--rz-camera-bg`, `--rz-camera-text`.
- Шрифти — тільки Manrope (UI) і JetBrains Mono (коди, суми, кількості, мітки колонок).
- Brand `#f77425` — лише для primary-дії, фокусу, поточного вибору й чекбоксів. Стан не позначати кольором бренду.
- Статус завжди має текст: `.rz-pill--ok/warn/danger/info`. Мапа статусів деталі: available→ok, reserved→warn, sold→danger.
- Тексти брати з локалізації (`src/**/*messages.ts`, uk — джерело). Не вигадувати й не перефразовувати. Якщо рядка немає, лишити заглушку в `[квадратних дужках]` і додати пункт в `OPEN-QUESTIONS.md`.
- Один модуль — одна сторінка `v2/modules/NN Назва.dc.html`, ізольована від інших модулів (спільні лише tokens.css і kit.css). Розділи по порядку: 1 Список → 2 Картка → 3 Форма → 4 Шторки й діалоги → далі специфічні. Кожен стан — кадр 1280×800 з номером `розділ.кадр`: дані, завантаження, порожньо, нічого не знайдено, помилка, немає прав, ліміт, лише перегляд, плюс специфічні.
- Модалки й шторки — схема 1b: шапка й футер `--rz-sheet-band`, тіло `--rz-sheet-body`, поля `--rz-sheet-field`, радіус md, без іконки-квадрата й eyebrow, заголовок 16/700.
- Права, тарифні фічі, підписка й фіче-флаги — окремі перевірки. Без права перегляду модуль приховати; без права на дію показати вимкнену кнопку з причиною; при прямому заході показати `.rz-state`.
- Розміри: desktop `--rz-control-h` 28/32; touch 44; склад і сканер — glove 56. Поле вводу на mobile — 16px.
- Друк — чорне на білому (`.rz-paper`), без кольорів бренду чи станів.
- Доступність: явний `<label>`; іконкова кнопка має `aria-label`; помилка → `role="alert"`; у таблиці перша колонка — `th scope="row"`.

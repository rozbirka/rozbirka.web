Завантажуємо дані…
{{ pulse }} верхня смуга — з анімацією pulse 1.6 с (motion-safe)
Skeleton повторює геометрію реального вмісту: ті самі висота рядка, колонки й радіуси. Показується через 300 мс, щоб не блимати на швидкій мережі.

Правила

  • Notice: danger → role="alert", інші → role="status". Іконка tone, текст — звичайний колір тексту, не колір тону.
  • Toast не містить інформації, якої немає на сторінці. Помилки, що блокують роботу, — Notice або ErrorState.
  • Затримка показу Skeleton 300 мс — пропозиція v2; у коді затримки немає.

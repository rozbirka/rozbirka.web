Правила

  • Увімкнений стан — завжди brand. Інших кольорів для вибору немає.
  • Checkbox у заголовку таблиці має стан mixed, коли обрано частину рядків сторінки.
  • Клікабельний увесь рядок з підписом, а не лише квадрат.
  • Switch не використовується у формах із кнопкою «Зберегти» — там Checkbox.
  • Підпис «Показувати продані» — демо; реального перемикача в коді поки немає.

Правила

  • Висота рядка — --rz-row-h (34 compact / 44 comfortable). Заголовок колонки — mono 11 uppercase.
  • Перша колонка — rowheader (th scope="row"), текст strong 500. Решта — text-muted. Числа — mono, праворуч, tabular-nums.
  • Обраний рядок — row-selected (brand 8%). Чекбокс заголовка — mixed, коли обрано частину сторінки.
  • Рядок, який не можна обрати чи змінити, — вимкнений чекбокс + замок + причина в title: «Деталь у відкритій інвентаризації — кількість рахує сесія.»
  • Поки є вибір, BulkBar займає місце тулбара фільтрів (як у коді). Фільтри застосовуються одразу, без кнопки «Застосувати».
  • Нове у v2: сортування за колонками, налаштування колонок, меню дій рядка «…». У коді цього немає.

Правила

  • Активний пункт: заливка fill-selected, текст strong, іконка brand. Без помаранчевого фону.
  • Групи: без заголовка (Головна) → Склад → Продажі → Гроші; Налаштування (account) — внизу. Порядок як у коді.
  • Mobile: 4 вкладки за mobilePriority (Головна 1, Запчастини 2, Замовлення 3, Фінанси 4) + «Ще». Активна вкладка — колір brand.
  • Rail: кожна іконка має aria-label і tooltip при наведенні/фокусі.
  • Topbar: одна primary-дія максимум; решта — secondary і меню «…».
  • Зміна v2: перемикач розбірки переїхав наверх sidebar (у коді — внизу). Вихід — у меню розбірки / акаунта.

Правила

  • Card: радіус md (8), border, surface; header 44px з border-bottom; padding — --rz-card-p (16 / 20).
  • Вкладені блоки всередині картки — surface-2 без власної тіні; радіус sm (6). Картка в картці заборонена.
  • FactList: label ліворуч (dim, 12–13px sans), значення праворуч. Порожнє значення — текстом із повідомлень («Нотаток немає…»), не тире.
  • KpiStrip: значення mono 28/500, одиниця mono 12 dim; не більше 4–5 клітинок у рядку.

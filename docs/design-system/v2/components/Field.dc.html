Правила

  • Висота поля у формі — control-h-lg (32/36), у тулбарі й фільтрах — control-h (28/32), на touch — 44.
  • Числа, гроші, коди — JetBrains Mono, вирівнювання праворуч, одиниця в суфіксі.
  • Фокус поля — рамка brand + мʼяке кільце brand-soft. Фокус кнопок — суцільне кільце --rz-focus.
  • Причина вимкнення — текстом у hint, не лише tooltip.
  • Placeholder не замінює label. Прихований label дозволений лише для пошуку.

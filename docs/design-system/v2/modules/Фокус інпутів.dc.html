Фокус полів · 3 варіанти
У кожному стовпці: звичайне поле, наведення, фокус, фокус з помилкою, пошук з іконкою у фокусі. Поля справжні — клікніть, щоб відчути фокус. Зліва — як зараз.
заразОранжева рамка + світіння
генератор
1aНейтральний
Рамка світлішає до сірої, фон поля трохи піднімається. Без оранжевого — бренд лишається для головних дій.
генератор
1bТонка оранжева рамка
Лише 1px рамка кольору бренду, без світіння навколо. Помітно, але не кричить.
генератор
1cСвітла рамка 2px
Рамка майже біла, подвійної товщини всередину поля — розмір не стрибає. Найчіткіший фокус без кольору.
генератор

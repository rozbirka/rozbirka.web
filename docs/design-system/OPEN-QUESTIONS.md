## Модуль 46 · Нова пошта (§1–3, web)
- D18. 2.2: у макеті редагування немає поля ключа, але Core змінює відправника, контакт і точку лише через сеанс підключення, а сеанс починається з ключа (збережений ключ Core не повертає). Поле «API-ключ» з’являється тільки коли змінено відправника, контакт або точку, з підказкою «Нового відправника, контакт чи точку Нова пошта перевіряє лише з ключем. Збережений ключ ми не показуємо — вставте його ще раз.» Зміна лише каси йде без ключа (`PUT shipping/preferences`).
- D19. 2.2: «Точка відправлення» в режимі редагування — вибір серед активних точок відправлення інтеграції (Core після збереження робить її єдиною типовою «Основна»).
- D20. 2.3: кількість чернеток у підсумку («у 2 відкритих замовленнях») Core не повертає — рядок без числа: «Чернетки доставки у відкритих замовленнях треба буде перевірити перед створенням ТТН.» Рядок «… не змінюються» складається з назв незмінених полів. Для зміни лише каси опис — «Зміни діятимуть для нових накладних.» (у Новій пошті нічого не перевіряється).
- D21. 2.8: Core не каже, хто й коли змінив налаштування (`np_configuration_changed`), тож замість «змінив Олег К. (19:42)» — «змінив інший користувач».
- D22. 1.18: «Вийти» не скасовує сеанс — перевірений ключ живе в сеансі Core до `expiresAt` (1 год), id сеансу зберігається в браузері; наступний вхід у майстер протягом цього часу починається з кроку 2. Після спливу сеансу — знову крок 1 з поясненням.
- D23. 3.3: дат «за 08–09.2026» і списку всіх накладних кабінету Core не дає (`connections` має лише `waybillCount`) — шторка показує відомі виклику накладні (із замовлення — одну) і «І ще N накладних.» без дат.
- D24. 3.5: `recover` відновлює доступ одразу після успішної перевірки; «Застосувати» лише закриває шторку й показує тост 3.9. Закриття шторки після успіху теж вважається застосуванням.
- D25. 3.6: Core не відрізняє «ключ поточного кабінету» від іншого непідтвердженого ключа (`np_historical_scope_unverified`), тож обидва випадки показуються як 3.7.
- D26. 3.2: «Відкрити ТТН» поки відкриває шторку «Дані накладної»; на картку ТТН (розділ 8) перемкнеться, коли вона з’явиться. Стан «Немає доступу» в замовленні видно лише з правом «Налаштування інтеграцій» — без нього Core не віддає список кабінетів.

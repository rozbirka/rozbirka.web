## Етап 1
- D1. Назва: **Rozbirka**, папка `Rozbirka Design System/`. (підтверджено)
- D2. Обсяг: основне — **кабінет + auth**. Лендинг: лише токени й короткий опис шару, без кіта.
- D3. Еталон для нових прототипів кабінету — **redesign** (`RedesignShell`, `Card`, `.type-redesign`, Manrope/JetBrains Mono). Старе покоління (`PageHeader`, `SectionPanel`) задокументоване як legacy.
- D4. Гілка: **main** @ 5d46b1f. `docs/ui` (гілка `feat/remove-free-parts`) лише довідково.
- D5. Мобільний застосунок (`rozbirka.mobile`) — **поза скоупом**.
- D6. Аналітика: продуктових подій у web немає. Документується лише безпечна телеметрія помилок (`observability/redaction.ts`). Агенти не додають трекінг у прототипи.
- D7. Еталони: e2e-скріншоти лендингу з репо. Кабінет відтворюю з коду, порівняння — через `visual_check.py`, коли з'являться скріншоти.

- D9. Колір заголовків: **#fff** (`text-white`), як у коді, хоча `app-ink` = #f6f4f2.
- ?1. `bg-brand-soft` / `bg-app-inset` — це помилка (токени забули додати) чи навмисна прозорість? Поки в кіті їх немає.

- D11. Висота контролів на desktop 28/32 замість 44. 44 — лише для `pointer: coarse`. Це відступ від правила коду «44px для кожного контролу кабінету» (input.tsx).
- D12. Фокус: у кнопок — суцільне кільце brand, у полів — рамка brand + мʼяке кільце brand-soft.
- D13. Checkbox, Radio, Switch — нові компоненти (у коді їх немає).
